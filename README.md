# English Quest（えいごクエスト）

6〜12歳向けの英語学習RPG。iPad の Safari で開いて「ホーム画面に追加」すると、全画面のアプリとして遊べます（PWA）。
広告なし・課金なし。ABC → フォニックス → 英検5級 → 4級 → 3級 → 準2級 → 2級 の順に、モンスターを倒しながら単語・文法・発音を覚え、各級の最後に英検形式の「ボステスト」に合格すると次の級が開きます。

読み書きだけで終わらないように、毎日 3分の「はなす」（英会話コーチ）モードがあります。コーチと英語で short conversation をして、会話中は止めずに、終わってから修正・スコア・宿題をまとめて受け取ります。

## はなす（英会話コーチ）

タブの 🗣️ から。1回およそ3分・6ターンの会話です。

1. コーチ（＝いま連れている「なかま」）が英語で質問し、下に日本語の意味が出ます（保護者メニューでオフにできます）
2. 子どもは今のむずかしさに合わせた形で答えます — Yes/No を選ぶ → ふたつから選ぶ → お手本をまねる → ことばを1つ入れかえる → 自分のことばで
3. マイクで聞き取り、うまく伝わらなくても会話は止めません。2回目でお手本を出し、それでも難しければ「パス」で先へ進みます
4. 「Let's stop here」（✕ → ここまでで おわる）でも、その時点までのまとめが出ます

終わると、いつも同じ形のまとめが出ます。

- きょうのスコア（5観点 × 5点 = 25点満点。マイクを使わなかった日は「はつおん」は採点せず、残りの観点で計算）
- 前回より のびた ところ（2回目以降は必ず1つ）／つぎの かだい
- きょう いえた えいご（自分のことばで答えた回は「こう いうと もっと いいね」＝完成版つき）
- なおすと もっと つたわるよ（言った英語 → もっと自然な言い方 → ひとこと説明。多くても2つまで）
- きょうの フレーズ5つ（あとで「ふくしゅう」のゾンビとして戻ってきます）
- 5分でできる宿題

週末は「📒 1週間の ふりかえり」で、スコアの推移・観点別の平均・くり返しつまずいた表現・言えた英語・来週の重点が見られます。保護者メニューの「記録」タブには、同じ内容をコピー／共有できるテキスト版（週次レビュー）があります。

むずかしさは結果に応じて1段ずつ自動で上下します（「はなす」画面の −／＋ で手動変更も可能）。

## 収録内容

- アルファベット26文字（聞く・大文字小文字・なぞり書き・頭文字）
- フォニックス 90語（短母音・二重字・マジックe・母音連字・子音連結）
- 英検5級〜2級の単語（`js/data/g5.js` … `g2.js`、各級テーマ別）と各級の問題バンク（空所補充・会話・並べかえ・読解）
- 旅行フレーズ 8シーン（あいさつ・空港・ホテル・レストラン・買い物・道案内・観光・困ったとき）
- 会話 8場面 × 各7ターン（じこしょうかい・がっこう・たべもの・すきなこと・かぞく・きょうのこと・ともだち・おでかけ）とキーフレーズ40

単語リストは各級の「目安」で、公式の出題範囲そのものではありません。

## iPad で使う

### 公開版（GitHub Pages）

<https://letter246.github.io/english-quest/> を iPad の Safari で開き、「共有 → ホーム画面に追加」。HTTPS なのでオフライン動作とマイクの発音チェックが使えます。ソースコードは <https://github.com/letter246/english-quest> にあります。

### いちばん簡単: 家の PC で配信する（同じ Wi-Fi 内）

```bash
python tools/serve.py 8765
```

上記は PC 内だけに公開します。iPad から見るには `tools/serve.py` の `127.0.0.1` を `0.0.0.0` に変えて起動し、iPad の Safari で `http://<PCのIPアドレス>:8765/` を開きます。
「共有 → ホーム画面に追加」でアイコンになります。※ この方法は HTTP なので、マイクでの発音チェックとオフライン動作は使えません（「聞いてまねする」練習になります）。

### おすすめ: 無料の静的ホスティングに置く（HTTPS・オフライン・マイク対応）

このフォルダをそのままアップロードするだけで動きます（ビルド不要）。

- GitHub Pages: リポジトリに push → Settings → Pages → Branch を選ぶ
- Netlify Drop: <https://app.netlify.com/drop> にフォルダをドラッグ
- Cloudflare Pages: ダッシュボードで「Upload assets」

公開した URL を iPad の Safari で開き、「共有 → ホーム画面に追加」。初回にマイクの許可を求められたら「許可」してください。

### 進み具合の引っ越し

進み具合は端末のブラウザ内（localStorage）に保存されます。別の端末や別の URL に移すときは、保護者メニュー（⚙️ → 計算問題または PIN）→「データ」→ 共有/コピー → 移動先で「読み込み」。

## 保護者メニュー

ホーム右上の ⚙️。子どもが勝手に開かないよう、かけ算の問題（または設定した4桁 PIN）で保護されています。

- 記録: 学習時間・正答率・直近14日の XP・級ごとの進み具合・英会話の記録（観点別の平均・学習ログ・週次レビューのコピー）・苦手な単語・最近の記録
- 設定: 1日の目標 XP、読み上げ速度、マイクの発音チェックのオン/オフ、会話中の日本語ヒント、効果音、PIN、開始レベル
- データ: バックアップの書き出し/読み込み、リセット、プロフィール削除

## 開発メモ

- 依存ライブラリなし（HTML + CSS + JS）。フォントのみ Google Fonts（Fredoka / Zen Maru Gothic）。
- 音声: 効果音は Web Audio で合成、読み上げは Web Speech API（iPad の英語音声）、発音チェックは `webkitSpeechRecognition`（iOS 14.5 以降の Safari）。
- 構成
  - `index.html` / `css/app.css` / `manifest.webmanifest` / `sw.js`（オフライン用）
  - `js/util.js` DOM ヘルパー、`js/audio.js` 音、`js/store.js` 保存、`js/content.js` カリキュラム生成、`js/engine.js` ゲームルール（アンロック・SRS・問題生成・バトル・報酬）
  - `js/ui_*.js` 画面（`js/ui_talk.js` が「はなす」の会話・まとめ・週次レビュー）、`js/app.js` 起動
  - `js/data/*.js` 教材データ（形式は `tools/CONTENT_SPEC.md`）
- 教材を増やす: `js/data/<級>.js` に単語や問題を足して `node tools/validate.js js/data/g5.js g5` で検査。
- 会話を増やす: `js/data/talk.js` に場面やターンを足して `node tools/talk-check.js` で検査（データの形式チェックに加えて、採点・むずかしさの上下・ログ生成を実際に動かして確認します）。
- アイコンを作り直す: `node tools/make-icons.js`
- Claude のアーティファクトとして公開する用のファイル: `node tools/build-artifact.js` → `dist/artifact.html`
